## การเตรียมรูปภาพและฟีเจอร์
การจัดการและเตรียมข้อมูลภาพสำหรับการฝึกสอนโมเดล CNN มีขั้นตอนหลักดังนี้:

* **การอ่านภาพและปรับขนาด (Resize 128x128):** อ่านไฟล์รูปภาพจากโฟลเดอร์คลาสต่างๆ ด้วย OpenCV และปรับขนาดรูปภาพให้อยู่ในขนาดมาตรฐานเดียวกันที่ 128x128 พิกเซล
* **การปรับสเกลฟีเจอร์ (Standardization):** แปลงค่าพิกเซลของภาพจากช่วง 0-255 ให้อยู่ในช่วง 0.0 ถึง 1.0 (float32) เพื่อช่วยให้โครงข่ายประสาทเทียมลู่เข้าสู่จุดตอบสนองที่ดีที่สุดได้เร็วขึ้น
* **การกรองรูปภาพที่เสียหาย:** ระบบมีฟังก์ชันตรวจสอบและข้ามไฟล์ภาพที่ไม่สมบูรณ์หรือเปิดไม่ได้โดยอัตโนมัติ เพื่อป้องกันการหยุดชะงักระหว่างประมวลผล

## โครงสร้างโมเดล CNN
ในแลบนี้มีการเปรียบเทียบโครงสร้างโมเดล CNN ทั้งหมด 2 รูปแบบ เพื่อศึกษาผลกระทบของความลึกโมเดลและจำนวน Epochs:

1. **Configuration 1** 
   * โครงสร้างประกอบด้วย 1 Convolutional Layer (32 Filters, Kernel 3x3)
   * ตามด้วย Max Pooling Layer (2x2), Flatten Layer, Dense Layer (64 Neurons) และ Output Layer (Softmax)
   * ใช้สำหรับการฝึกสอนระยะสั้นจำนวน 5 Epochs

2. **Configuration 2** 
   * โครงสร้างประกอบด้วย 2 Convolutional Layers (32 และ 64 Filters)
   * ใช้ Max Pooling Layer (2x2) หลังแต่ละ Conv Layer
   * มี Flatten Layer, Dense Layer (128 Neurons), เพิ่ม Dropout (0.3) เพื่อป้องกันการท่องจำ (Overfitting) และ Output Layer (Softmax)
   * ใช้สำหรับการฝึกสอนจำนวน 10 Epochs

## สรุปหน้าที่ของแต่ละไฟล์ในโปรเจกต์

โครงสร้างโค้ดถูกแบ่งออกเป็นโมดูลต่าง ๆ ตามหน้าที่อย่างเป็นระเบียบ เพื่อความเป็นระเบียบและง่ายต่อการบำรุงรักษา:

* **`data_loader.py` (ระบบดึงและอ่านข้อมูลภาพ):** ทำหน้าที่ค้นหาซับโฟลเดอร์ย่อยในโฟลเดอร์ `flowers/` อ่านไฟล์ภาพของแต่ละคลาส แปลงเป็น Array พร้อมคัดกรองไฟล์ภาพที่ไม่สมบูรณ์ออกโดยอัตโนมัติ
* **`preprocessing.py` (ระบบเตรียมข้อมูลฟีเจอร์):** ทำหน้าที่ปรับขนาดรูปภาพให้เท่ากันที่ 128x128 พิกเซล และทำการ Standardization ค่าพิกเซลให้อยู่ในช่วง [0, 1]
* **`split_data.py` (ระบบแบ่งชุดข้อมูล):** แบ่งชุดข้อมูลภาพออกเป็น 3 ส่วนด้วยวิธี Stratified Split ได้แก่ Training Set สำหรับฝึกสอน, Validation Set สำหรับตรวจสอบระหว่างเทรน และ Testing Set สำหรับการวัดผลขั้นสุดท้าย
* **`cnn_model.py` (วิศวกรสร้างสถาปัตยกรรมโมเดล):** กำหนดโครงสร้าง CNN Configurations (Config 1 และ Config 2) รวมถึงการตั้งค่า Activation Functions (ReLU, Softmax)
* **`evaluate.py` (กรรมการวัดผลและสร้างผลลัพธ์):** คำนวณค่า Accuracy และ Loss ของโมเดล, สร้างภาพ Confusion Matrix และพล็อต กราฟ Training History (Accuracy/Loss) แล้วบันทึกไฟล์ลงโฟลเดอร์ outputs/
* **`test_cnn.py` (ระบบสุ่มสแกนและสุ่มตรวจ):** ทำหน้าที่ทำนายผลบนชุดข้อมูลทดสอบ (Test Set) และสร้างภาพแสดงตัวอย่างผลการทำนาย (Prediction Sample) พร้อมแสดงเลเบลจริงและเลเบลที่ทำนาย
* **`main.py` (ผู้จัดการควบคุมระบบหลัก):** ไฟล์หลักที่ทำหน้าที่ควบคุมลำดับการทำงานทั้งหมดตั้งแต่ Step 1 ถึง Step 6 และสั่งบันทึกไฟล์ผลลัพธ์ทั้งหมดลงโฟลเดอร์ `outputs/`

3. **`training_history.png`:** กราฟเปรียบเทียบค่า Accuracy และ Loss ระหว่าง Training Set และ Validation Set ในแต่ละ Epoch
