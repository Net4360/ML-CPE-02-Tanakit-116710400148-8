โปรเจกต์สอน AI ดูรูปสภาพอากาศด้วย Neural Network (Sunny vs. Rainy)
นายธนกฤต ชูจิต sec2 รหัส 116710400148-8
โปรเจกต์นี้คือการนำเทคนิค Neural Network (MLP: Multi-Layer Perceptron) มาใช้สอนให้คอมพิวเตอร์เรียนรู้การมองเห็นภาพวิวทิวทัศน์ เพื่อจำแนกสภาพอากาศว่าภาพนั้นเป็นวันแดดออก (Sunny) หรือวันฝนตก (Rainy)

เป้าหมายหลักคือการสร้าง Pipeline การทำงานตั้งแต่การอ่านรูปภาพ การเตรียมฟีเจอร์ การแบ่งชุดข้อมูล การสร้างและเทรนโครงข่ายประสาทเทียม ไปจนถึงการประเมินผลและการสุ่มทดสอบทำนายผลภาพจริง

การเตรียมรูปภาพและฟีเจอร์ (Preprocessing & Feature Pipeline)
การประมวลผลภาพในงาน Neural Network ชุดนี้ มีเทคนิคการจัดการข้อมูลเพื่อประหยัด RAM และทำให้ระบบทำงานเร็วขึ้น ดังนี้ครับ:

แปลงเป็น RGB & ย่อขนาด (Resize 100x100):
อ่านไฟล์ภาพด้วย OpenCV แล้วแปลงระบบสีจาก BGR เป็น RGB จากนั้นย่อขนาดรูปทุกรูปให้เท่ากันที่ 100x100 พิกเซล

ประหยัดความจำด้วย uint8 (Memory Optimization):
เก็บข้อมูลรูปภาพในรูปแบบ Array 3 มิติ (100, 100, 3) ที่มีค่าพิกเซล 0-255 (ชนิด uint8) ซึ่งใช้พื้นที่ RAM น้อยกว่าแบบ float32 ถึง 4 เท่า ช่วยให้โหลดรูปภาพปริมาณมากๆ ได้โดยเครื่องไม่ค้าง

ยกการปรับสเกลไปไว้ในโมเดล (In-Model Rescaling & Flatten):
แทนที่จะจับภาพยืดเป็นเส้นตรงหรือหาร 255 ตั้งแต่แรก ในโปรเจกต์นี้เราส่งภาพ 3D เข้าโมเดลโดยตรง แล้วให้ชั้น Rescaling(1/255) และ Flatten() ข้างใน Neural Network เป็นตัวจัดการเปลี่ยนค่าพิกเซลให้อยู่ในช่วง 0-1 และแผ่เป็นเส้นตรงให้อัตโนมัติ

โครงสร้างสมอง AI (Neural Network Architecture)
โครงข่ายประสาทเทียมในโปรเจกต์นี้ใช้สถาปัตยกรรมแบบ Deep MLP ที่มีระบบป้องกันการเรียนรู้แบบท่องจำ (Overfitting):

Input Layer: รับภาพขนาด 100x100x3 ปรับสเกลข้อมูล และแผ่เป็นเวกเตอร์ขนาด 30,000 ฟีเจอร์

Hidden Layers (3 ชั้น):

ชั้นที่ 1: Dense(256) + BatchNormalization() + Dropout(0.4)

ชั้นที่ 2: Dense(128) + BatchNormalization() + Dropout(0.4)

ชั้นที่ 3: Dense(64) + Dropout(0.3)

Output Layer: ใช้ Sigmoid (กรณี 2 คลาส) หรือ Softmax (กรณีหลายคลาส) สำหรับส่งออกเป็นค่าความน่าจะเป็น

ระบบควบคุมการเทรน: มี EarlyStopping ช่วยหยุดการเทรนทันทีเมื่อโมเดลเริ่มไม่พัฒนา และ ReduceLROnPlateau คอยปรับลด Learning Rate เมื่อการเรียนรู้เริ่มติดขัด

ไฟล์แต่ละอันทำหน้าที่อะไรบ้าง?
โครงสร้างโค้ดถูกแบ่งออกเป็นมอดูลต่างๆ ตามหน้าที่อย่างเป็นระเบียบ:

data_loader.py (มือดึงรูป): ค้นหาโฟลเดอร์ย่อยใน WeatherImages ดึงรูปภาพ Sunny และ Rainy แปลงเป็น Array พร้อมคัดกรองรูปภาพที่เสียหรือเปิดไม่ได้ออกให้อัตโนมัติ

preprocessing.py (คนเตรียมฟีเจอร์): ปรับขนาดรูปภาพเป็น 100x100 พิกเซล แปลงสีเป็น RGB และจัดรูปแบบโครงสร้างข้อมูลให้อยู่ในลักษณะ Array พร้อมใช้งาน

split_data.py (คนแบ่งเค้กข้อมูล): แบ่งข้อมูลออกเป็น 3 ส่วน คือ Train (70%) สำหรับให้ AI เรียนรู้, Validation (10%) สำหรับเฝ้าระวัง Overfitting ระหว่างเทรน และ Test (20%) สำหรับวัดผลสอบขั้นสุดท้าย

nn_model.py (วิศวกรสร้าง AI): ประกอบโครงสร้าง Neural Network, กำหนด Loss Function, Compile โมเดล, ตั้งค่า Callbacks และทำหน้าที่เทรนโมเดลพร้อมบันทึกไฟล์ .keras

evaluate.py (กรรมการวัดผล): คำนวณค่า Accuracy, แสดง Classification Report, วาดรูป Confusion Matrix และพล็อต Training History Graph (กราฟ Accuracy/Loss) เพื่อดูพัฒนาการของโมเดล

main.py (ผู้จัดการใหญ่): ไฟล์หลักที่ควบคุมสเต็ปการทำงานทั้งหมดตั้งแต่ Step 1 ถึง Step 6 และบันทึกผลลัพธ์ทั้งหมดลงในโฟลเดอร์ outputs/

test_nn.py (ด่านสุ่มตรวจ): โหลดโมเดลที่เทรนเสร็จแล้ว สุ่มหยิบรูปจากชุดทดสอบมา 4 รูป ทำนายผล แล้วเปิดหน้าต่างแสดงรูปภาพพร้อมระบุคำทาย (Pred), ค่าจริง (True) และเปอร์เซ็นต์ความมั่นใจ (Confidence %)

runall.py (ปุ่มรันอัตโนมัติ): สคริปต์สำหรับสั่งรันทุกไฟล์ Python ในโฟลเดอร์ตามลำดับอักขระเพื่อทดสอบระบบทั้งหมดในคำสั่งเดียว
