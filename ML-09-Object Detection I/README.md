## ภาพรวมโปรเจกต์
โปรเจกต์นี้เป็นการประยุกต์ใช้ **Machine Learning / Deep Learning** ในการจำแนกประเภทอารมณ์จากใบหน้า (Facial Emotion Recognition) โดยเปรียบเทียบสถาปัตยกรรม 2 รูปแบบหลัก ได้แก่ **01-R-CNN** และ **02-Fast-R-CNN** 

ระบบทำการดึงข้อมูลภาพโดยตรงจากโฟลเดอร์แยกตามคลาสอารมณ์ (เช่น `Angry`, `Happy`, `Sad` ฯลฯ) เพื่อทำการฝึกสอนโมเดล ประเมินประสิทธิภาพวัดค่าความแม่นยำ ทดสอบทำนายภาพนิ่ง และทดสอบการตรวจจับแบบเรียลไทม์ผ่านกล้องเว็บแคม

---

## การเตรียมข้อมูล (Dataset Structure)
ชุดข้อมูลรูปภาพจัดเก็บไว้ที่ระดับโฟลเดอร์หลัก (`dataset/`) โดยแบ่งย่อยตามชื่อคลาสอารมณ์ดังนี้:

```text
ML-09-Object Detection I/
├── dataset/
│   ├── Angry/     (ไฟล์รูปภาพ .jpg, .png)
│   ├── Happy/     (ไฟล์รูปภาพ .jpg, .png)
│   └── Sad/       (ไฟล์รูปภาพ .jpg, .png)
├── 01-R-CNN/
└── 02-Fast-R-CNN/
```

- **Image Resizing:** ปรับขนาดภาพเข้าสู่โมเดลที่ขนาด `64x64` พิกเซล
- **Normalization:** แปลงค่าพิกเซลจากช่วง 0–255 ให้อยู่ในช่วง `0.0 ถึง 1.0`
- **Data Splitting:** ใช้คำสั่ง `image_dataset_from_directory` แบ่งข้อมูลเป็น Training Set (80%) และ Validation Set (20%) โดยอัตโนมัติ

---

## สถาปัตยกรรมโมเดลที่เปรียบเทียบ
1. **01-R-CNN:** 
   - โครงสร้างแบบ `Sequential` มาตรฐาน ประกอบด้วย Convolutional Layers, Max Pooling, Flatten และ Dense Layers
   - เหมาะสำหรับการจำแนกฟีเจอร์พื้นฐานแยกตามพื้นที่
2. **02-Fast-R-CNN:**
   - โครงสร้างแบบ Functional API ที่เพิ่มเลเยอร์จำลอง **RoI Feature Pooling** (`MaxPooling2D(pool_size=4)`) ก่อนเข้าเลเยอร์ Flatten
   - ช่วยกระชับฟีเจอร์แมปและเพิ่มประสิทธิภาพในการประมวลผลตามแนวคิด Fast R-CNN

## โครงสร้างไฟล์และหน้าที่การทำงาน (Project Modules)

สคริปต์การทำงานถูกแบ่งออกเป็น 2 โฟลเดอร์การทดลอง (`01-R-CNN` และ `02-Fast-R-CNN`) โดยแต่ละโฟลเดอร์ประกอบด้วยไฟล์หลักดังนี้:

- **`train.py` (ระบบฝึกสอนโมเดล):** อ่านข้อมูลจากโฟลเดอร์ `dataset/` อัตโนมัติ สร้างสถาปัตยกรรมโมเดล CNN ทำการฝึกสอน (Training) ตาม Epochs ที่กำหนด และบันทึกโมเดลลงไฟล์ `outputs/model.keras`
- **`evaluate.py` (ระบบประเมินผล):** โหลดโมเดลที่เทรนแล้วมาทดสอบกับ Validation Set คำนวณค่า Accuracy แสดงผลตาราง `classification_report` และบันทึกสรุปผลลงไฟล์ `outputs/evaluation.json`
- **`image_test.py` (ระบบทดสอบภาพนิ่ง):** สุ่มเลือกรูปภาพจากโฟลเดอร์คลาสอารมณ์ นำมาทำนายผล แสดงค่า True Label / Predicted Label และความมั่นใจ (Confidence) พร้อมวาดข้อความระบุผลลัพธ์ลงบนภาพแล้วบันทึกที่ `outputs/image_result.jpg`
- **`realtime_test.py` (ระบบทดสอบเรียลไทม์):** เปิดกล้องเว็บแคมเพื่อจับภาพใบหน้าและทำนายอารมณ์แบบเรียลไทม์ พร้อมแสดงกรอบและชื่อคลาสอารมณ์บนหน้าจอ

## ผลลัพธ์ในโฟลเดอร์ `outputs/`
หลังจากรันสคริปต์การทำงานครบถ้วน ทั้งใน `01-R-CNN` และ `02-Fast-R-CNN` จะเกิดไฟล์ผลลัพธ์ในโฟลเดอร์ `outputs/` ดังนี้:

1. **`model.keras`**: ไฟล์น้ำหนักและสถาปัตยกรรมโมเดลที่ผ่านการฝึกสอนแล้ว
2. **`evaluation.json`**: ไฟล์สรุปผลค่าความแม่นยำ (Accuracy Score) ของโมเดล
3. **`image_result.jpg`**: ภาพตัวอย่างผลการสุ่มทำนายอารมณ์พร้อมป้ายกำกับ
