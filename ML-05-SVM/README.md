## เตรียมรูป(Preprocessing)

ปกติแล้วคอมพิวเตอร์มองภาพเป็นแค่ตัวเลขเยอะๆ ถ้าเราโยนรูปสีกว้างๆ ไปให้มันเลย มันจะงงและทำงานช้ามาก ผมเลยต้องเขียนโค้ดเตรียมรูปภาพก่อน ดังนี้ครับ:

1. **ทำเป็นภาพขาวดำ (Grayscale) & ย่อขนาด (Resize):** 
   ค้อน กรรไกร กระดาษ เราดูที่ "รูปร่าง" ของนิ้วมือ สีผิวหรือสีฉากหลังไม่ได้สำคัญ ผมเลยจับแปลงเป็นขาวดำให้หมด และย่อขนาดรูปให้เหลือแค่ 100x100 พิกเซล คอมพิวเตอร์จะได้ไม่ต้องอ่านข้อมูลเยอะเกินไป
2. **จับยืดเป็นเส้นตรง (Flatten) & ปรับสเกล (Normalization):** 
   รูปภาพเดิมเป็นกริดสี่เหลี่ยม เราต้องจับมันมาเรียงต่อกันเป็นแถวเดียวยาวๆ (10,000 ตัวเลขต่อ 1 รูป) และเอาค่าสีไปหาร 255 เพื่อให้ตัวเลขทุกตัวมีค่าอยู่แค่ระหว่าง 0 ถึง 1 AI จะได้คำนวณง่ายๆ ไม่เจอตัวเลขโดดๆ
3. **คัดเฉพาะจุดเด่น (PCA):** 
   ตัวเลข 10,000 ตัวต่อ 1 รูปมันยังเยอะไป! ผมเลยใช้เทคนิคที่เรียกว่า PCA (Principal Component Analysis) เพื่อบีบอัดและดึงมาเฉพาะ "จุดเด่นที่สำคัญที่สุด" ของภาพเท่านั้น วิธีนี้ทำให้ AI เรียนรู้ไวขึ้นเยอะมาก

## Kernels (สมอง 3 แบบของ SVM)

โจทย์กำหนดให้เราต้องทดสอบสมองของ SVM 3 แบบ (Kernels) ซึ่งแต่ละแบบมีวิธีแบ่งแยกรูปภาพต่างกันครับ:

1. **Linear Kernel (สายขีดเส้นตรง):** 
   ตัวนี้จะพยายามลากเส้นตรงๆ ทื่อๆ เพื่อแบ่งกลุ่มข้อมูล ถ้าภาพดูง่ายๆ เส้นตรงก็เอาอยู่ และทำงานไวมาก
2. **Polynomial Kernel (สายเส้นโค้ง):** 
   ตัวนี้จะอัปเกรดขึ้นมาหน่อย สามารถวาดเส้นแบ่งแบบโค้งงอได้ ช่วยให้แยกแยะข้อมูลที่เริ่มมีความซับซ้อนได้ดีขึ้น
3. **RBF Kernel (สายล้อมจับ):** 
   ตัวท็อปของ SVM เลยครับ! แทนที่จะขีดเส้น มันจะสร้างขอบเขตโค้งมนมาห่อหุ้มกลุ่มข้อมูลไว้เลย ทำให้แยกแยะรูปภาพที่มีความซับซ้อนและทับซ้อนกันได้ดีที่สุด (ปกติมักจะทายแม่นที่สุด)

## ไฟล์

เพื่อไม่ให้โค้ดปนกันมั่ว ผมเลยแบ่งไฟล์ Python ออกเป็นส่วนๆ ตามหน้าที่การทำงานเลยครับ:

*   **`data_load.py` (มือดึงรูป):** มีหน้าที่มุดเข้าไปในโฟลเดอร์ ดึงรูปค้อน กรรไกร กระดาษ ออกมาจัดเรียงให้พร้อมใช้งาน
*   **`preprocess.py` (คนทำความสะอาด):** รับรูปมาแปลงเป็นขาวดำ ย่อขนาด และปรับตัวเลขให้เป็นระเบียบตามที่อธิบายไว้ข้างบน
*   **`svm_model.py` (โรงงานสร้าง AI):** เป็นตัวเก็บสูตรการสร้างโมเดล ในนี้จะรวมการทำ สเกลข้อมูล, ทำ PCA, และตัว SVM เข้าไว้ด้วยกัน พร้อมให้เราสั่งได้ว่าจะใช้ Kernel แบบไหน
*   **`main.py` (ผู้จัดการใหญ่):** ไฟล์หลักที่เราใช้รันโปรแกรม! มันจะไปเรียกไฟล์อื่นๆ มาทำงานตามลำดับ เริ่มจากโหลดรูป -> แบ่งรูปเป็นชุดเรียนกับชุดสอบ -> สั่งเทรนโมเดลทั้ง 3 Kernels -> และประเมินคะแนนความแม่นยำ
*   **`test_svm.py` (ด่านสุ่มตรวจ):** เอาไว้เล่นสนุกๆ ครับ พอมันเทรนเสร็จ เราสามารถรันไฟล์นี้เพื่อสุ่มหยิบรูปในคลังมา 4 รูป แล้วให้ AI ทายว่าคืออะไร พร้อมเซฟรูปผลลัพธ์มาให้เราดูด้วย
